# 🎵 SpotDown

SpotDown es una aplicación de escritorio desarrollada en **Python** que permite descargar canciones, álbumes y playlists de Spotify de forma sencilla mediante una interfaz gráfica moderna creada con **CustomTkinter**.

La aplicación está diseñada para ofrecer una experiencia intuitiva, mostrando el progreso de las descargas, un historial de canciones descargadas y opciones de configuración para personalizar la carpeta de destino.

---

## ✨ Características

- 🎵 Descarga de canciones individuales.
- 📀 Descarga de álbumes completos.
- 📃 Descarga de playlists.
- 📊 Barra de progreso durante la descarga.
- 📂 Selección de carpeta de destino.
- 📝 Historial de descargas.
- ⚙️ Configuración persistente.
- 🖼️ Pantalla de bienvenida (Splash Screen).
- 🎨 Interfaz moderna con CustomTkinter.
- ❌ Cancelación de descargas.
- 📁 Apertura rápida de la carpeta de destino.

---

## 🛠️ Tecnologías utilizadas

- Python 3.12
- CustomTkinter
- Pillow

## 📥 Instalación

Clona el repositorio:

```bash
git clone https://github.com/M1NUS5/SpotDown.git
```

Entra a la carpeta del proyecto:

```bash
cd SpotifyDownloader
```

Instala las dependencias:

```bash
pip install -r requirements.txt
```

---

## ▶️ Ejecución

Ejecuta la aplicación con:

```bash
python main.py
```
